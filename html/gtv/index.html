02 / A QUICK PIT STOP

Ready to hit the road?

Here’s how to choose and install your version.

Which Windows version do I need?+

Choose x64 for most PCs with an Intel or AMD processor. Choose ARM64 for Windows on ARM devices, including PCs with a Snapdragon processor.

Check your processor and system type in Settings → System → About. Download the matching EXE and run it to install GTV.

Intel or Apple Silicon?+

Open Apple menu → About This Mac. If it lists an Apple M-series chip, choose Apple Silicon. If it lists an Intel processor, choose Intel.

Open the downloaded DMG, then drag GTV into Applications.

AppImage or DEB on Linux?+

Both Linux downloads are for 64-bit Intel / AMD computers. Choose DEB for Debian or Ubuntu and open it with your software installer.

Choose AppImage for a portable download. Make it executable in the file’s properties, then run it. Your distribution may require FUSE support.
